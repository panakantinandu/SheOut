# Contributing

**This project is not accepting code contributions.**

SheOut is proprietary. All rights are reserved, and the source is public
for demonstration and evaluation only - see [LICENSE](LICENSE). Accepting
a pull request would mix code owned by somebody else into a codebase that
is meant to stay wholly owned, which is a problem that is far easier to
avoid than to unpick later.

Pull requests will be closed unpicked. That is not a judgement on the
work; it is the licence.

## What is welcome

**Security reports.** Privately, by email, never as a public issue. See
[SECURITY.md](SECURITY.md). This is the one thing worth interrupting
anybody over.

**Bug reports and questions.** Open an issue. Say what you did, what you
expected and what happened. If it touches somebody's personal data or
could be used against a user, it is a security report instead - email it.

**Feedback on the product.** Especially from women who would use it. That
is worth more to this project than a patch.

Ask. The licence forbids use, copying and deployment without written
